# saude — dashboard pessoal de saúde

Single-file HTML (`index.html`) com abas: Exames de Sangue, Genética, Bioimpedância,
Dieta, Treinos (periodização), Treino Alternativo (musculação + corrida), Diário de
Treino, Endoscopia, Sono, Qualidade de Vida, Medicações. Publicado via GitHub Pages
(`master`), desenvolvido na branch `claude/html-git-pages-publish-5lrihm`.

## Preferências do usuário (Luiz)

- **Prioridade atual: perder gordura, não ganhar massa.** Ao dar recomendações de
  dieta/treino, otimizar para perda de gordura — não sugerir abordagens de
  recomposição corporal ou ganho de massa como se fossem o objetivo, a menos que o
  usuário peça explicitamente para mudar de prioridade.
- Condição relevante: **condromalácia patelar grau 2 bilateral** — sempre considerar
  impacto/ROM ao sugerir exercícios de perna.
- Objetivo de corrida em andamento: voltar a correr 10km em 50min (ver planilha em
  `tab-treino-alt`).
